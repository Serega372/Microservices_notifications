# Kafka Cluster
### Назначение

Данный репозиторий содержит конфигурацию Kafka-кластера, используемого в системе уведомлений для асинхронной передачи сообщений между сервисами.

Kafka используется как транспортный слой между:
- notifications-gateway
- email-service
- sms-service
- push-service

### Архитектура

- Kafka Brokers: 2
- Режим работы: KRaft (без ZooKeeper)
- Развёртывание: Docker / Docker Compose
- VM: отдельная виртуальная машина

### Топики
Используются следующие Kafka-топики:
- email
- sms
- push

`notifications-gateway` публикует сообщения в соответствующий топик,
каждый сервис-получатель читает только свой топик.

### Особенности
- ZooKeeper не используется
- Кластер предназначен для демонстрации отказоустойчивой асинхронной обработки
- Гарантируется at-least-once доставка сообщений
